Коммит 1:
Рабочая папка - каталог с файлами проекта, которые я редактирую
Индекс - промежуточная область, куда через 'git add' попадают изменения
Коммит - сообщения, которые показывают, какое изменение было сделано

Коммит 2:
Git - инструмент, GitHub - сервис для совместной работы

Коммит 3:
git status - показывает текущее состояние
git diff - показывает разницу между рабочей папкой и индексом
git diff --staged - показывает разницу  между индексом и последним коммитом

Ветки - указатель на коммит, при новом коммите ветка передвигается вперед. Слияние объединяет истории двух веток
